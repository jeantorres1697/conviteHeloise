# 🎂 Convite Digital - 3 Anos da Heloíse Manuelle

Este é um projeto de convite digital interativo desenvolvido para o aniversário de 3 anos da minha filha Heloíse Manuelle. O objetivo foi criar uma experiência moderna, prática e encantadora para os convidados, facilitando o acesso às informações e a confirmação de presença.

📍 **[Clique aqui para visualizar o projeto online](https://jeantorres1697.github.io/conviteHeloise/)**

---

## ✨ Funcionalidades

- **Design Responsivo:** O convite adapta-se perfeitamente a dispositivos móveis e desktops.
- **Informações do Evento:** Data, hora e local detalhados.
- **Confirmação de Presença (RSVP):** Formulário integrado para os convidados informarem nome e quantidade de adultos/crianças.
- **Integração com GPS:** Botão direto para abrir a localização no Google Maps.
- **Estética Temática:** Identidade visual voltada para festas infantis.

## 🚀 Tecnologias Utilizadas

Este projeto foi construído utilizando:

- **HTML5:** Estrutura do conteúdo.
- **CSS3:** Estilização, layout (Flexbox/Grid) e animações.
- **Formspree** Envio dos dados do formulário.
